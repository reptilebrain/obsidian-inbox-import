# Obsidian Inbox Import

[![Tests](https://github.com/reptilebrain/obsidian-inbox-import/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/reptilebrain/obsidian-inbox-import/actions/workflows/tests.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Move loose `.txt` files from the Windows Desktop and Documents folders into an existing Obsidian vault's `00_Inbox`, changing only the extension to `.md` and preserving the file bytes.

Supports Windows PowerShell 5.1 and PowerShell 7, dry runs, age filtering, safe filename conflict handling, and logs outside the vault.
